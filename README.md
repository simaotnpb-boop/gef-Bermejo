# MODO CELULAR (Para GitHub Pages)

Esta carpeta contiene **exclusivamente la versión móvil** para que funcione directamente en cualquier celular (iPhone y Android) al subirla a GitHub Pages.

---

## 📱 ¿Cómo funciona?
- El archivo principal `index.html` es la **aplicación móvil directa** (con navegación táctil inferior: *Asistentes*, *Escáner*, *Resumen*).
- Al subir el contenido de esta carpeta a tu repositorio en **GitHub**, el enlace:
  `https://simaotnpb-boop.github.io/Proyecto-gefBermejo/`
  abrirá **únicamente el modo móvil**, sin mostrar la versión de escritorio.

---

## 🚀 ¿Cómo subirlo a GitHub?
1. Abre tu repositorio en GitHub: [https://github.com/](https://github.com/)
2. Arrastra y sube todos los archivos de esta carpeta `Celular/` a la raíz de tu repositorio.
3. Espera 1 minuto a que GitHub Pages actualice.
4. Abre el enlace en tu celular:
   `https://simaotnpb-boop.github.io/Proyecto-gefBermejo/`

---

## 🔒 Conexiones y Base de Datos
- Las conexiones a **Firebase Firestore** y los datos iniciales **están 100% intactos**, sin ninguna modificación.
